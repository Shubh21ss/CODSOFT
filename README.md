## 🗂️ Project Details

### Task 1 — To-Do List
A command-line To-Do List application that helps users manage their daily tasks efficiently.

**Features:**
- Add new tasks
- View all tasks
- Mark tasks as done
- Update existing tasks
- Delete tasks
- Data saved to a local JSON file (persists between runs)

**Run:**
```bash
cd Task1_ToDo
python todo.py
```

---

### Task 2 — Calculator
A simple yet complete calculator that handles basic arithmetic operations.

**Features:**
- Addition, Subtraction, Multiplication, Division
- Modulus and Power operations
- Division by zero error handling
- Continuous calculation in a single session

**Run:**
```bash
cd Task2_Calculator
python calculator.py
```

---

### Task 5 — Contact Book
A full-featured contact management application with search and CRUD functionality.

**Features:**
- Add contacts (name, phone, email, address)
- View all contacts in a formatted table
- Search by name or phone number
- Update contact details
- Delete contacts
- Data saved to a local JSON file

**Run:**
```bash
cd Task5_ContactBook
python contact_book.py
```
